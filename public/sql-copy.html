Migration 003–005: सेवाएँ और जयपुर क्षेत्र + Migration 006: सुरक्षित Job Matching

यह SQL शुरुआती 12 सेवाएँ और जयपुर के 12 प्रमुख क्षेत्र जोड़ता है: वैशाली नगर, मानसरोवर, मालवीय नगर, जगतपुरा, झोटवाड़ा, राजा पार्क, C-Scheme, सांगानेर, टोंक रोड, विद्याधर नगर, श्याम नगर और सोडाला। पिछली गलत seed list से जुड़े पाँच generic पुराने क्षेत्र केवल inactive होंगे; कोई रिकॉर्ड delete नहीं होगा। Migration 006 सुरक्षित matching और contact access देती है; Migration 007 matched work दिखाती है; Migration 008 job start और completion OTP जोड़ती है; Migration 009 गलत OTP attempts को सुरक्षित रूप से गिनती है। आगे Management App से क्षेत्र जोड़ने, संपादित करने और बंद करने की सुविधा बनेगी।

SQL कॉपी होने के बाद Supabase → SQL Editor में नया query खोलकर paste करें और Run दबाएँ। Success आने पर Provider App refresh करें।
